Proyecto #1: Despliegue de una página
web para la gestión de una frutería
El objetivo de este proyecto es diseñar y desplegar una aplicación web dinámica
para una frutería que gestiona sus productos y permite mostrar su catálogo a
clientes. La aplicación se construirá con HTML, PHP y MariaDB, ejecutándose
sobre un servidor Apache en Ubuntu.
La Frutería Online es una pequeña tienda que desea exponer sus productos por
Internet y gestionar su inventario internamente. El sitio web deberá tener:
● Página de inicio: mostrará un título con el nombre de la frutería, un enlace
al catálogo de frutas y otro enlace a un formulario para insertar nuevos
productos.
● Catálogo: mostrará todas las frutas en una tabla (nombre, precio, cantidad
e imagen). Además, se deben poder eliminar productos de la base de
datos mediante una entrada de texto y un botón de eliminar, así como
poder cambiar la cantidad que hay de cada fruta. añade por defecto a la base de datos la fruta de la pasión
● Inventario: contendrá un formulario con los campos nombre, precio,
cantidad y URL de la imagen, así como un botón para guardar. Al enviar el
formulario, se insertará el nuevo producto en la base de datos.
